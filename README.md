# 🐾 PetHub

**PetHub** is a pet-care management platform designed to make pet ownership simple, organized, and convenient.

## ✨ Features

* 👤 User registration and authentication
* 🐶 Create and manage pet profiles
* 🏥 Manage pet health and vaccination records
* 📅 Book and manage pet-care appointments
* ✂️ Discover grooming and veterinary services
* 🔔 Receive important pet-care notifications
* 👨‍⚕️ Connect with pet-care service providers
* 🛡️ Secure user and admin management

## 🎯 Objective

PetHub brings essential pet-care services and pet information together in one platform, helping pet owners easily manage their pets and access the services they need.

## 🛠️ Tech Stack

* **Frontend:** React / HTML / CSS / JavaScript
* **Backend:** Node.js / Express
* **Database:** MongoDB
* **Authentication:** JWT
* **Version Control:** Git & GitHub
